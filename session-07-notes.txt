LLM restrictions:
- LLM does not have recent events information
- only LLM is not enough to answer recent event related questions?

AI Agent
- it's LLM having access to processed info and some particular web API/service
- First tries to get answer from already available info or goes internet
- AI Agent focus on task

Agentic AI
- it's LLM having LLM and multiple web APIs/services
- Tried to get work done via LLM capability + multiple web APIs/services
- Agentic AI focus on goal, a goal can have multiple tasks

AI Agent:
- Some entity, which is capable of communicating with LLM and external entities
- Al agents are advanced, autonomous, or semi-autonomous software systems that analyze, plan, and execute tasks independently.
- We do not have contorl or workflow assigned to AI Agent
- Still AI Agent has some limitations of which services it can reach
- Under proepr governance, they make decisions and still adhere to established business rules
- AI Agent improves efficiency over time via learning from past experiences, 
  this point separates it more from Generative AI, it does not have past experiences

Agentic AI
- Agentic Al refers to autonomous artificial intelligence systems designed to achieve specific goals with minimal human supervision.
- Unlike traditional Al, which operates within predefined constraints and requires human intervention, agentic Al exhibits autonomy, adaptability, and goal-driven behavior.
- It uses Al agents-machine learning models that mimic human decision-making-to solve problems in real-time by interacting with their environment.

Gen AI vs AI Agent vs Agentic AI

Feature:
- Primary Function
- Dependency
- Tool Access
- Learning Capability
- Example Use Case

Gen Al:
- Generates new content (text, images, videos, code)
- Works based on trained data
- No real-time access to tools or APIs
- Learns from historical data (not real-time)
- Writing articles, creating designs

Al Agent:
- Performs specific predefined tasks automatically
- Depends on predefined rules and APIs
- Limited access to tools for specific actions
- No continuous learning, follows instructions
- Fetching flight data or sending alerts

-- Autonomy Level
-- Example Tools/Models
--- Low
--- ChatGPT, DALL.E, Midjourney
---- Medium
---- Customer service bots, automation systems

Agentic Al:
- Plans, reasons and acts independently toward a goal
- Uses reasoning, planning and feedback loops
- Dynamic access to multiple tools and APIs
- Continuously adapts to context and outcomes
- Booking flights based on preferences and constraints

---- High
---- AutoGPT, Devin Al, Gemini 2.0 with planning capabilities

--- High

---- Engineering and coding agents that write, execute, and debug code autonomously.
