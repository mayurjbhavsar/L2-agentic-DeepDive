LangGraph memory management

Types of memories in LangGraph:
1) State - Request level memory and share among nodes of the same graph. When request is over, the state is deleted.
2) Checkpointer - Thread level memory, short term memory - store in the RAM or in database
3) Store - User level memory, long term memory
