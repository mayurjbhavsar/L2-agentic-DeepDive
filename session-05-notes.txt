Types of search:

1) Simple search
Please find out employees working Pune office.
SELECT * FROM EMP WHERE LOCATION = 'PUNE'

2) Similarity search
Please find out good hotels nearby
Find out nearby hotels where in the comments you find the words like good/better/best/nice/awesome/cool

3) Semantic search
Similarity search + think from multiple dimensions
Semantic search = Similarity search + Context/Intent of asking the question
Example:
  Prompt: Where can I purchase tickets?
  Prompt + context
